Briefs produits chaque nuit à partir de flux choisis : un terme validé de la carte doit figurer dans le titre ; un modèle de langage remplit une grille fixe, puis le code contrôle chaque chiffre dans la source. « Vérifié dans la source » : le chiffre figure bien dans le document ; « relayé » : le document l'attribue à un tiers, non vérifié chez ce tiers ; « affirmé par le média » : la page n'a pas pu être lue, le fait vient du résumé du flux ; « chiffre non retrouvé » : le modèle l'a donné mais il n'apparaît pas dans le document, à ne pas reprendre sans contrôle. Aucune prédiction ; rien du texte des articles n'est conservé.
